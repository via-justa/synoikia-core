# §13 Verification

Tests come first, and a change never makes a test weaker to make it pass.

**Coverage floors.** `pnpm --filter @synoikia/core test:coverage` measures V8 coverage. It fails if `gate/`, `auth/`, `approvals/`, `sandbox/` or `crypto/` go below their floors in `packages/core/vitest.config.ts`.

**Test areas.**

| Area                     | The tests prove that                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Listeners                | Both listeners start, `/healthz` works on each, and a route of one listener returns 404 on the other.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| SDK contract             | The manifest schema refuses bad input (unknown widgets, bad ids, `sdk` ranges). RPC types round-trip. `runPlugin` maps errors to codes. The SDK refuses an older core for `sensitiveResult`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Access levels            | Each branch of `effectiveAccess`. New groups start at `ask`. New operations in an existing group get their own level. Changes reset acknowledgement. A regroup never gives wider access.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Database and crypto      | AES-GCM round-trip. AAD binding (a value moved to another row fails). API objects never hold secrets. Master key creation and rotation. Migrations keep data and behavior.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Plugin host              | The child has the permission flags (no file writes, clean environment). IPC timeouts. Restart with backoff after a crash. `PLUGIN_UNAVAILABLE`. 503 when disabled. A bundle change forces a sync.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Repositories and install | Index schema. A wrong sha256 fails. Signed repositories refuse bad or missing signatures and block installs after a key change. Unsigned installs need confirmation. A plugin from another repository is never replaced. The default repository is added once.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Catalog sync             | Changes, `stale`, locked seeds disable rules, no service without a catalog, version-triggered sync, the lock for each instance, `sensitiveResult` storage.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Sandbox                  | Only the bindings are reachable. `require`, `process` and `fetch` are absent. Loops stop. Memory limit. Errors can be caught in the sandbox. Approval time does not count.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Gate and pre-approval    | The pipeline order. Attestation before access. `OPERATION_DISABLED` gives the reason. Targets fail closed. Each match operator. All targets must match. Missing fields do not match. Over the rate limit, a human decides. Expiry. Locked operations never pre-approved. Result masking. A plugin change during an approval refuses the call.                                                                                                                                                                                                                                                                                                                                                                                |
| Approvals                | A client with forms only cannot approve, except opted-in plain writes. URL prompt → approval page decides. Decline denies. Completion notice. TOTP (new for locked), CSRF and the literal on the page. Access checked again. Single use. Timeout denies. Restart denies. A caller that cannot park and has no prompts is denied. Parked executions: each write runs once, the owner check, the limits, `resume` results, the end at endpoint stop. The approval card has no approve path and no external origin. Session grants: only the page gives one, locked and typed-confirmation operations stay out, level `none` and the ceiling still refuse, revoke and expiry. The approval page asks for TOTP once per browser. |
| Admin authentication     | Setup only when empty. argon2. TOTP and recovery codes. Lockout. Session expiry. CSRF. OIDC allow policy, linking, local sign-in rules.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| MCP authentication       | Each mode and scope. 401 with the RFC 9728 header. PKCE required. Resource and audience binding. Refresh rotation and reuse detection. DCR switch. Cloudflare Access JWT.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Admin API                | Each route. 409 cases. Masked secrets. `config` audit events with redacted diffs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Admin UI                 | Component tests for each page: sign-in, TOTP, OIDC, access levels, the Write dialog, bulk Write, schema forms, the registry picker. A browser smoke test.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MCP endpoints            | Routing by slug. Tool descriptions from the manifest. `search` hides disabled operations by default. `execute` end to end with the MCP SDK client.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Notifications            | ntfy JSON. Webhook signature. Retries. No approval events or links. No raw parameters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Maintenance              | With a mocked clock: sync delay, daily times, the mid-session check, housekeeping.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Plugins                  | Each plugin repository has its own tests: unit tests, `checkConformance`, and end-to-end tests on `@synoikia/core/testing` with a fake upstream (§4.5).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

Plugins build and test outside this repository, against the published `@synoikia/plugin-sdk` (with `checkConformance`) and `@synoikia/core/testing` (the harness). Any plugin can run the same checks.
